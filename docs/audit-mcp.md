# 历史核查归档与升级说明

2026-11-03：LOOM-051 E1 已移除外部接入。应用不再监听核查连接，不提供 stdio 适配器、连接配置、启用、撤销或外部额度控制。旧连接配置不能访问执行器。

内部 Main 继续使用只读核查能力；原编辑提案与作者审阅流程保留。

打开原作品，在 **设置 → 作品与备份 → 历史核查归档** 查看旧外部任务。可查看历史用量、检查点引用，以及各版本结果和原文证据。读取不会调用模型、更新旧任务状态或将旧任务转为内部可执行任务。旧结论需核对当前资料版本后再使用。

旧连接索引、结果、证据、检查点、账本及原 ID 保留在原位置。索引损坏时显示读取错误，原文件保留；不会据此建立新授权或重启任务。未完成的旧记录也只展示为归档。

以上外部接入移除发生于 2026-11-03 的 E1 阶段。当前开发版的应用内任务保存与恢复流程见 [使用指南](USER-GUIDE.md#跨章检查使用任务卡)；旧外部任务不参与自动接续，历史用量与限制保持不变。

# ZestLoomer 0.1.0-beta.3 · 预览版

2026-10-28。对照 GitHub 的 Loom `0.1.0-beta.2`（`77ca7c1`），汇总后续本地开发成果。Windows x64 安装版、免安装版与校验文件见 [v0.1.0-beta.3](https://github.com/lemonwhitele-maker/ZestLoomer/releases/tag/v0.1.0-beta.3)。

- 整合新版工作区：单层顶栏、纸张式正文、滚动标题、浮动工具、底栏统计、可调宽目录与窄屏浮层，保留经典布局。
- 新增浮层查找替换、蓝色选区、版心选择、工具常驻、专注与 F11 禅意，可选打字机和中文选区配对。
- 增加正文与章节大纲关联、按编号匹配和伏笔表；新作品提供只读人物／设定示例与可编辑副本。
- Agent 正文读取改为绝对行号与分页，按行范围或精确选区生成受版本保护的提案；新的正文修改候选统一段落换行，可能改变选区外排版，审阅时展示实际差异。普通保存不进行这项格式化。
- 增加默认关闭的超重 Agent 上下文选项，按书库保存设置；改进近期历史与提案最新状态投影。历史使用确定性摘录，不是模型语义摘要。
- 设置整理为写作显示、Agent 偏好、超重agent、AI 接入、作品与备份五区。
- 改进切章撤销与阅读位置、字数和换行索引、切书与刷新缓存、AI 滚动跟随、大文档对照后台计算及弹窗按需加载。
- 应用、安装包、可执行程序和快捷方式统一更名 ZestLoomer；兼容旧 Loom 书库、配置、环境变量和阅读位置。
- 提供 Windows x64 安装包、免安装 ZIP、版本说明与 SHA-256 清单。检查结果见 [本次验证记录](../verification/ZestLoomer-beta.3-2026-10-28.md)。

已知问题：长会话精确历史重读与预算仍有阻断，完整真实模型验收未通过。实体悬浮卡、行内 AI、正文 Diff 投影、逐段采纳与分卷待后续实现；中文 IME、系统缩放及独立电脑升级体验仍需分别验收。

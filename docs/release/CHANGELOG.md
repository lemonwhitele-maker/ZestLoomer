# 0.1.0-preview.20261019 · 临时预览版

对比现有 0.1.0-beta.2：

- 正文与大纲：一对一关联、双向跳转、按中文或数字章号自动匹配。
- 伏笔：新增表格编辑、逐行保存、起始/回收章节关联及 Agent 查阅提案。
- 超重 Agent：新对话可追加自定义提示、本章大纲、本章正文窗口、前三章大纲和上一章结尾；可选上下文默认关闭。
- 书库：API、工具、工作区及自定义提示配置统一存于书库 `.loom`，移动书库后按作品 ID 恢复列表。
- 修改与审阅：按绝对行号读取和编辑，支持行前/行后/文首插入和续写，改善段落空行衔接及词句、换行对照。
- 作品：支持修改作品名称。

预览版使用独立程序标识、用户资料目录和默认空书库。现有主分支、beta.2 标签及附件不变。

本次不调用用户的真实模型或读取个人书库。构建、测试和上传审计的实际结果以本次预览发布记录为准；不沿用旧版验收数字。

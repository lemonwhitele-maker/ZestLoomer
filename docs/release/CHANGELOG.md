# 更新记录

## 0.1.0-preview.20261024 · 临时源码版

比较基线：上次临时源码 `0.1.0-preview.20261019`（提交 `cc03d2db573e7c0169bbdd0d5da122bd60f9a015`）。

- **名称与兼容**：开发版界面和桥接 API 更名为 ZestLoomer；新增 `.zestloomer`、本机资料目录、新环境变量和阅读位置键，保留旧 Loom 书库与本机配置兼容。
- **人物与设定示例**：人物基础模板增加“经典发言”。新作品附带只读人物、设定示例，支持阅读、导出和复制；示例不作为本书事实参与自动关联和高亮。
- **正文提案与读取证据**：正文 edit 候选统一段落换行，审阅时显示提示。选区和同版本已读内容可累计为修改证据，并提供缺失范围提示。
- **AI 历史上下文**：最近八个已完成回合与更早历史分区，摘录优先使用最终回答；增加可见性、失败事件、摘录缓存及预算诊断。摘录采用确定性方式，不宣称完成语义总结。
- **提案状态同步**：预处理、主模型与只读查询使用同一轮冻结的最新持久化状态；编辑提案按可还原的改动块投影，保留接受与条件撤销保护。

临时版保留已知缺陷：历史路径片段尚不能精确定位单轮，长历史重读可能超过上下文预算。对应真实模型验收未通过；本次按现有源码提供预览，详见 [已知问题](KNOWN-ISSUES.md)。

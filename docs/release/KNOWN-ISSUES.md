- 没有自动更新。更新前备份书库并关闭应用；ZestLoomer 与旧 Loom 使用独立安装身份，不自动替换旧安装。

- **长会话中的精确历史重读与上下文预算仍有已知问题**：指定历史轮次可能返回整段会话，工具重读也可能触发 `CONTEXT_BUDGET`。建议缩小任务范围，必要时新建会话。此项尚未通过完整真实模型验收，见项目中的 `docs/verification/LOOM-039-acceptance-2026-10-23.md`。

- 实体悬浮卡、行内 AI、正文 Diff 投影、逐段采纳和分卷尚未实现；Markdown 以源码编辑。
- 真实模型测试需要显式配置；本次打包验收不调用外部模型，不代表所有模型与工具调用协议均兼容。
- 超重 Agent 选项默认关闭，必要上下文超预算会报错；不承诺增加模型容量、降低费用或改善写作质量。
- 新的正文修改提案会统一完整候选的段落换行，选区外排版也可能变化，请核对最终差异；普通手工保存不进行这项格式化。
- 会话输入草稿不承诺跨重启恢复；每个会话仅保留最近一轮完整运行日志，回收站没有永久删除和自动清理入口。
- 书库内 AI 配置的加密密钥不保证可跨电脑直接解密，搬迁后应重新核对配置。
- 完整运行日志包含书稿、会话及模型请求内容。反馈前检查附件中的私人文字、密钥和本机路径。

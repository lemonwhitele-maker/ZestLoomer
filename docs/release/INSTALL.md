# Loom Windows 安装说明

版本：0.1.0-beta.2。适用 Windows 10 / 11 x64，当前为内测版。

## 安装

1. 双击 `Loom-0.1.0-beta.2-win-x64-setup.exe`。
2. 选择安装语言，阅读许可，选择安装位置，再完成安装。
3. 从桌面或开始菜单打开 Loom。无需安装 Node.js、npm 或另外下载 Electron。
4. 点击「新建作品」并选择保存位置，或点击「打开作品」选择包含 `book.json` 的作品目录。

安装包完整包含应用运行文件，安装时无需联网；调用 AI 服务时需要联网并自行配置服务地址和密钥。默认只为当前用户安装，不要求管理员权限；选择的目录需对当前用户可写。请把作品保存在独立的文档目录，避免保存到程序安装目录。

本安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。发布方尚未配置可信签名；请核对来源与 SHA-256 校验值，并遵循电脑的安全策略。

## 数据、更新与卸载

作品在你选择的目录；应用设置在 `%APPDATA%\Loom`。安装包不附带测试书稿或个人设置。

首版没有自动更新。升级前使用应用的「完整备份」，关闭 Loom，再运行新版本安装包覆盖安装。卸载通过 Windows 的「已安装的应用」完成。配置为保留应用设置；外部作品目录不由卸载器管理。独立电脑与跨版本升级验收仍需完成，详见 `KNOWN-ISSUES.md`。

## 校验文件

`SHA256SUMS.txt` 提供安装包和随附文本的 SHA-256。可在 PowerShell 中运行：

```powershell
Get-FileHash .\Loom-0.1.0-beta.2-win-x64-setup.exe -Algorithm SHA256
```

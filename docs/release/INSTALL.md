# 临时预览版安装说明

下载本次预览发布中的 Windows x64 安装包，按向导安装 **Loom Preview**。安装器未签名，没有自动更新。

预览版使用独立安装标识、程序、快捷方式及 `%APPDATA%/Loom Preview` 资料目录。默认书库为该目录中的 `BookList`，首次为空；不会自动迁移正式版配置或原作品。

用测试作品或正式书库的副本体验新功能。手动打开原作品仍会直接操作原文件。API 配置需要在预览版自行填写。请保留正式版和原书库备份。

现有 beta.2 安装包及主分支保留。本预览包无需覆盖正式版安装目录，卸载预览版时保留其资料目录。

`SHA256SUMS.txt` 提供本次公开附件的 SHA-256；可使用 PowerShell `Get-FileHash` 核对。
